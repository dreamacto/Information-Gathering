# Offline analysis

- `product_triage.py`: product/framework candidate classification from existing run artifacts.
- `healthcare_privacy_triage.py`: privacy-oriented endpoint and field-name triage without retaining values.
- `fingerprint_deepening.py`: offline mapping from fingerprints to review branches and approval queues.
- `review_intelligence.py`: offline aggregation of candidates and per-target review dossiers.

Root-level modules with the same names remain compatibility entrypoints.
